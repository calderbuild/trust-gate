TrustGate

59–90% of on-chain agent reputation feedback in a 2026 study of the ERC-8004 registry shows Sybil patterns.

Reputation is self-reported. An agent can write its own good reviews. TrustGate makes that impossible.

source: arxiv.org/abs/2606.26028

The rule

An agent can never write its own history.

An interaction only resolves once the counterparty signs it with their own key. Not the agent. Not an admin. The other side.

createReceipt() → counterparty signs → VERIFIED / MISMATCH

One disputed receipt is a veto — it doesn't get diluted by ten clean ones.

Three contracts, one job each

The ledger, split by concern.

01

AgentIdentity

Registers agents. Tracks active vs. revoked. Owns nothing else.

02

ActionLedger

Records receipts. Resolves VERIFIED/MISMATCH only when the counterparty's own signature recovers correctly.

03

TrustGate

Read-only over both. previewAccess (free) and checkAccess (real tx) run identical logic — they can never disagree.
